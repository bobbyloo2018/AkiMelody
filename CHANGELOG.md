# Changelog

## v1.0.0 — Initial Release

**Welcome to AkiMelody!** 

Play YouTube Music with a beautiful visual experience.

### Features

* Stream and download music from YouTube Music
* Clean, modern desktop interface with dynamic theming
* Favorites, playlists, and music library management
* Community themes and playlists via GitHub
* Spotify Likes import
* YouTube Music account linking
* Background audio visualizer with palette engine
* Keyboard media key support
